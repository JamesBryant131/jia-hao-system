# 嘉豪系统 · 校园多人版

网页放在 GitHub Pages，所有玩家连接同一套 Cloudflare Worker 与 SQLite Durable Object。玩家只需用户名和密码。站长首次上线需要一个 GitHub 账号、一个可使用 Workers 的 Cloudflare 账号，以及可运行 Node.js 22 或更高版本的电脑。

## 1. 建立校园服（站长操作一次）
1. 在 Windows 解压压缩包。进入解压后的 server 文件夹，在文件夹内打开终端。
2. 执行 npx wrangler@4 login，按浏览器提示登录 Cloudflare。
3. 执行 npx wrangler@4 deploy。第一次使用 Workers 时，按提示设置 workers.dev 子域名。记下最终输出的 https://…workers.dev 地址。数据库绑定在 server/wrangler.toml 中声明，部署时自动建立。
4. 在同一目录执行 npx wrangler@4 secret put ADMIN_PASSWORD。在隐藏输入提示中粘贴你为 tdy 指定的密码并回车。以后可以用同一命令更换。tdy 是保留用户名，只能通过登录进入；权限在服务端检查。
5. 用文本编辑器打开压缩包根目录的 config.js，把 Worker 地址填入双引号，保存。全班使用同一个地址。
6. 将 index.html、config.js、campus.js、legacy.js、style.css、mascot.png 上传到 GitHub 仓库根目录。在仓库 Settings → Pages 中选择 Deploy from a branch，选择分支及 /(root)，保存并打开 Pages 给出的网址。server 文件夹可作为源码保留，管理员密码仅填写到第 4 步的隐藏提示中。

## 2. 上线验收
* 用「登录」进入 tdy 管理区。再在另一浏览器注册普通宿主，检查其页面只有四个分区。
* 甲注册后获得 40 豪意值。甲发布 10 豪意值的悬赏，余额降至 30。乙打开「任务区 → 玩家悬赏」，约 5 秒内可以看到；乙完成后结算得到 10 点。甲撤回尚未结算的悬赏会收到退款。
* 在管理区输入已注册用户名可以授予或撤销管理权限。保留管理员 tdy 不受角色编辑影响。
* 旧版入口保留原设备的单机游戏。要读取旧存档，请保持原 GitHub Pages 网址和浏览器。校园账号与旧单机存档分别保存。

## 3. 玩法
每天北京时间零点刷新，每位宿主随机分配最多三项校园任务。搜索支持标题、完成条件、发布者或豪意值，并能选择奖励升序或降序。
每条玩家悬赏限一人领取，由发布者出资；发布者不能自领。管理员撤销悬赏也会向原发布者退款。
在系统奖励区兑换卫衣、墨镜、耳机等虚拟外观，再点击衣橱中的装扮即可换装或卸下。每个部位可穿戴一件。商城下架不会收走已经兑换的物品。
约 1–4 分钟触发一次奇遇，包括限时每日任务双倍、下一件装扮半价、额外豪意值。离开后再次登录会检查已到期的奇遇。

任务灵感取自公开讨论中的黑卫衣、校园电音模仿等元素。任务为本游戏原创，使用课间、午休和活动时段，玩家扮演的是自己的虚构角色。
